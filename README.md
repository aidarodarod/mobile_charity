# ФПА — готовое мобильное демо

## Как загрузить на GitHub

1. Создай публичный репозиторий.
2. Через Add file → Upload files загрузи СОДЕРЖИМОЕ этой папки: index.html, styles.css, app.js и папку assets. index.html должен лежать в корне репозитория.
3. Открой Settings → Pages. В Source выбери Deploy from a branch, затем main и /(root), нажми Save.
4. После публикации готовая ссылка появится в том же разделе Pages.

Сборка, npm и установка зависимостей не нужны. Все фото, логотипы и шрифты уже внутри assets. Четыре новые фотографии взяты из обновлённых подготовленных рядов Figma.

Каждый из трёх рядов благотворительности листается отдельно. Ряды команды двигаются в разные стороны при вертикальной прокрутке. Основная мобильная ширина — 393 px. Для перехода прямо к галерее добавь #charity в конец опубликованной ссылки.

Официальная инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
